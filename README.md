# Knowledge Base Site

公開知識閱讀網站的發布程式庫，只保存經確認可公開的網站成品。

目前只有初始化文件，尚未發布文章或啟用 GitHub Pages。

已選定的更新方式：由 Agent 在工作完成後產生經核准的公開成品，檢查後 commit、push 到本庫 main，再確認 GitHub Pages 部署。公開篩選及 Pages 尚待實作；目前尚未自動同步。本庫不持有私人知識庫的讀取憑證。

## 發布範圍

- 公開文章、圖表、來源說明及必要網頁資產，須先確認發布範圍。
- 原始附件、私人心得、未公開筆記及私人知識庫的 Git 歷史不匯入本程式庫。
- 搜尋索引、摘要及下載檔案也屬公開內容，必須與正文一起檢查。

## 維護

先閱讀 [AGENTS.md](AGENTS.md)。網站預定使用 GitHub Pages 免費方案與 GitHub 提供的網址；不引入外部託管、付費服務或新 API 整合。

commit、push 與網站部署是不同動作，須分別驗證與回報。
